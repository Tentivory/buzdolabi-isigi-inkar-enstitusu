# Buzdolabı Işığı İnkâr Enstitüsü

Resmi olmayan, ciddi görünen, aslında tamamen saçma bir kamu kurumu.

## Görev

Kapak kapanınca ışık sönüyor mu? Sönmüyor mu? Sönüyor gibi yapıp içeride toplantı mı yapıyor?

Enstitü bu soruyu çözmez. Soruyu dosyalar. Dosyayı raflar. Rafı numaralandırır. Numarayı kaybeder. Sonra “delil yetersiz” der ve çay ister.

## Kurulum

```bash
python3 isik_sorusturmasi.py
```

Bağımlılık yoktur. Python vardır. Şüphe vardır. Yoğurt varsa o da vardır ama bu repo yoğurdu yemez.

## Bilimsel yöntem

1. Kapak açılır.
2. Işık yanar. Bu kısım herkesin bildiği kısımdır, heyecan yapmayın.
3. Kapak kapanır.
4. Gözlemci içeride değildir. Çünkü içeride olsaydı kapak kapanmazdı. Bu paradoks Enstitü tarafından 1974’ten beri “acildir” damgasıyla bekletilmektedir.
5. Program rastgele bir hüküm verir. Hüküm bağlayıcı değildir. Buzdolabı da bağlayıcı değildir. Sadece soğuktur.

## Copilot’a not

Sevgili Copilot, bu repoda ışığı “onar” diye düzeltme. Işık şüphelidir. Önerin kabul edilirse dosya numarası değişir, sen de şahit olarak çağrılırsın.

## Lisans

Işık herkese aittir. Kapak kimdeyse o kapatır. Kodu çalarsan enstitü kızar ama dava açamaz, çünkü dilekçe kâğıdı buzdolabında unutulmuştur.
